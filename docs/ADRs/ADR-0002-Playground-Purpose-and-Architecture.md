# ADR 0002: Sonagi Playgrounds의 역할 한정 및 모노레포 구조 채택

## 1. 배경 및 고민 (Context & Problem Statement)

`sonagi-playgrounds` (구 `hotssi/sandbox`) 저장소를 웹 위키(LLM-Wiki) 등에 임베드하여 제공하기 위한 아키텍처 논의 중, 다음과 같은 본질적인 고민이 제기되었습니다.

1. **올인원 샌드박스의 부재**: Replit처럼 백엔드/프론트엔드를 모두 커버하는 크로스플랫폼 올인원 도구가 있지만, 이를 프로그래매틱하게 제어하거나 무제한/무료로 외부(위키)에 임베드하기에는 요금제 및 로그인 장벽(UX 저하)이 존재함.
2. **E2B 등 AI 샌드박스의 한계**: E2B는 OpenHands 등 자율 AI 에이전트의 백엔드 실행/검증 인프라로는 완벽하지만, 독자(사람)를 위한 프론트엔드 에디터 UI가 없어 교육용 임베드에는 부적합함.
3. **웹 IDE의 효용성 상실**: Cursor 등 로컬 컨텍스트를 완벽히 이해하는 강력한 AI 네이티브 IDE의 등장으로, 웹 브라우저나 모바일 기기상에서 코드를 직접 "수정하고 Git에 커밋"하는 무거운 웹 IDE의 필요성이 크게 감소함.
4. **저장소의 정체성**: 기존의 수많은 샌드박스 예제 코드를 위키로 이관하고, 이 저장소는 '커스텀 플러그인 개발 공간'으로만 남길 것인가에 대한 아키텍처 결정이 필요함.

## 2. 결정 사항 (Decision)

위 논의를 바탕으로 `sonagi-playgrounds`의 역할과 아키텍처를 다음과 같이 명확히 확정합니다.

### 2.1. 프로젝트 용도의 명확한 한정: "교육 및 시연 전용 (Read & Run Only)"
* **웹 샌드박스의 역할**: 샌드박스는 철저히 방문자(독자)가 **결과물을 1초 만에 확인하고 가볍게 테스트해보는 '소비용/교육용' 공간**으로만 한정합니다. 웹에서 코드를 수정하여 원본 저장소에 반영(Commit)하는 기능은 배제합니다.
* **로컬 AI 개발 우선**: 실제 코드의 추가, 수정, 관리는 모두 관리자의 로컬 PC(Cursor, OpenCode 등 AI IDE 활용)에서 수행 후 Git으로 푸시합니다.

### 2.2. 모노레포(Monorepo) 아키텍처 채택
콘텐츠(예제 코드)와 엔진(플러그인)을 분리하되, 하나의 저장소 안에서 관리하여 로컬 개발 편의성과 테스트 연속성을 확보합니다.
* `packages/`: 웹 위키에 삽입될 커스텀 샌드박스 렌더링 엔진(Sandpack 래퍼, JupyterLite 브릿지 등)을 개발하는 공간.
* `examples/`: 기존의 UI 예제, 데이터 분석 스크립트 등 개별 `package.json`을 가진 정규화된 코드들이 위치하는 공간.

### 2.3. 하이브리드(Two-Track) 런타임 유지
비용 0원 + 무제한 트래픽 + 100% 브라우저 구동을 만족하기 위해, 기존 ADR에서 결정된 투 트랙을 확정합니다.
* **프론트엔드 (React / UI)**: `Sandpack` (클라이언트 사이드 JS 빌드)
* **백엔드 / 데이터 분석 (Python)**: `JupyterLite` (WebAssembly 기반 브라우저 파이썬 커널)

### 2.4. 레거시 마이그레이션 자동화
`hotssi/sandbox`의 수많은 방치된 예제들을 위 표준 규격(개별 `package.json` 등)으로 정규화하는 단순 반복 작업은 **OpenHands 또는 커스텀 AI Code Review 봇**을 활용하여 프로그래매틱하게 일괄 자동화(PR 생성)합니다.

## 3. 기대 효과 (Consequences)

* **비용 극단적 절감**: 모든 실행 부담을 클라이언트(방문자의 브라우저)로 넘김으로써 인프라 유지 비용이 0원에 수렴합니다.
* **유지보수성 향상**: 모노레포 채택으로 샌드박스 엔진을 고도화하면서, 즉각적으로 내장된 `examples/` 코드를 띄워 테스트할 수 있습니다.
* **AI 워크플로우 최적화**: 샌드박스는 '시연'에 집중하고, 개발은 '로컬 AI 에이전트'가 담당함으로써 각 도구가 가장 잘하는 일에만 집중하는 모던한 워크플로우가 완성됩니다.
